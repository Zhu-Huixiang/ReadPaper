# 插画保留与混合排版

用于用户要求“插画版”“仿照草稿视觉元素”，或已经认可生图草稿中的丰富插画。先看用户选定的草稿与当前 PDF；需要参考实现时，查看 [Zeva 已认可样例](accepted-example.md#插画混合终稿zeva)。普通文字或连线修订不需要重新生图。

## 这次交互暴露的问题

Zeva v1 保留了顶部少量原插画，其余区域用简化的矢量机器人、卡片和文字框重绘。科学内容可以继续核对，但“插画与草稿对照”的要求没有被满足。用户认可的 v2 直接引用草稿中的插画区域，再用 TikZ 重排主要文字、公式和连线。

| v1 的具体问题 | v2 有效的处理 | 后续绘图应保留的判断 |
|---|---|---|
| 执行动作退化为折线机械臂；效果成为抽象示意 | 保留机械臂姿态、动作轨迹、容器及前后场景 | 动作和效果都有具体视觉证据，读者才能立即理解“做了什么、改变了什么” |
| 记忆卡只剩框和色条 | 保留卡片上的交互缩略图、叠放厚度与阶段区分 | 记忆内容及组织关系应能从画面读出来 |
| 紫色 Memory Context Encoder 变成普通平面文字框 | 复用醒目的立体模块，清楚接入与接出，公式安排在邻近区域 | 核心模块的视觉重点是信息层级的一部分 |
| 顶部好看，策略内部、训练和部署被简化 | 对每个相关区域复用对应素材 | 插画保留要覆盖整条计算与执行链 |
| 编译通过仍有局部遮挡、错误输入对应 | 重排并核对科学连线，查看整页和密集局部 | 视觉质量、科学正确和编译成功分别检查 |

这次有效的是素材保留与精排的分工，不是固定的裁片数量、实验器皿、三栏版式或紫色编码器。新论文按自己的机制选场景和视觉重点。视觉认可也不表示论文已读懂、实现已验证或实验结论成立。

## 在原工作规格中补一张视觉对应表

沿选定草稿的阅读顺序，按有意义的场景或模块分组记录，不必逐像素描摹或另建主文档。

| 草稿区域／素材 | 表达的信息及需要保留的特征 | 终稿位置与处理 | 核对结果 |
|---|---|---|---|
| 动作与效果区域 | 执行姿态、轨迹、前后场景和局部特写 | 对应模块复用插画，另排正确标签和连线 | 主体完整，前后顺序正确 |
| 记忆区域 | 有场景内容的卡片，以及窗口、堆叠或检索关系 | 保留素材形态，用计算流连接 | 无空白卡片替代或语义丢失 |
| 关键模块 | 参考中的大小、材质、立体感、配色与显著位置 | 保留视觉重心，公式放近旁 | 整图中仍容易定位 |

将表中示例替换为当前草稿的实际区域；训练和部署中的插画同样纳入。用户点名的元素应逐一对应。若插画表达与论文冲突，修正其科学语义，同时尽量保留可用的视觉素材；不能为了“完全照图”沿用错误的箭头或时序。

## 插画与精确排版如何配合

1. **保留源图。** 优先用 `graphicx` 的 `trim`／`viewport` 与 `clip` 在页面合成时引用所需区域；保持原图文件不变，保留裁切位置或源码调用以便追溯。只作页面裁切无需重新生图。若需要改变插画内容、去字或补画，按 imagegen 技能使用内置编辑工具，并保留选定原版。
2. **裁出完整的语义单元。** 场景前后图、主体与轨迹、卡片缩略图与层次、立体模块的正侧面通常应一起保留。边缘留出少量余量，检查是否夹入旧公式、半条箭头或相邻面板。构图边界与放置尺寸由实际素材决定；像素坐标要换算为图片在 TeX 中的自然尺寸，不能默认一个像素就是一个 `bp`，先用局部渲染确认坐标方向和裁切范围。
3. **分开管理正确性。** 主要标签、公式、输入输出、时间索引与计算箭头由 TikZ 精排并逐项核对。原插画内准确、清楚且不冲突的标签可以保留为位图；不清楚或错误的文字不能因难以替换而继续使用。重排后检查新旧标签重叠和重复端口。
4. **保住视觉重点。** 参考中显著的关键模块应维持容易辨认的面积、材质和输入输出关系；普通模块的视觉强度应与其作用相称。补充公式可用邻近区域、整行公式带或适当增加画布高度承载，插画不能被挤成看不清的角标。
5. **检查素材清晰度。** 保留原生分辨率和纵横比，避免多次压缩。按裁片有效像素与最终放置大小判断；大尺寸导出和简单放大不会增加真实细节。需要更大印刷尺寸时再处理确实不足的素材，不因标称 DPI 一项就重新生成用户满意的全图。
6. **交付可复用的组合。** PDF 中的文字、公式、连线可编辑，插画仍是位图；如实描述。源码使用相对图片路径，源码包包含所有依赖。不能把整张生图转存 PDF 说成精排或纯矢量成品。

## 生图提示词

将下面的骨架替换为当前论文的具体模块与参考元素，不原样传入占位文字。先写能约束画面的内容，再写风格形容词。用户已有满意草稿时，保留要求应具体到区域。

> 为《论文标题》绘制单页中文插画式方法图。论文附件负责科学内容；参考图负责构图、材质和阅读顺序；本篇已选定草稿中的指定插画需逐区保留。图的核心故事是：具体场景 → 执行的动作 → 可观察的结果 → 下一步决策。
>
> 视觉区域：逐区列出必须保留的主体、动作姿态、前后场景、卡片内容、内部模块及训练部署插画。明确它们表达什么，不能只写“丰富、生动、好看”。保持参考中的材质、景深、层次与配色；不要用通用图标、简笔画或空白文字框替换指定插画。
>
> 视觉重点：点名当前论文的关键模块，说明它的显著位置、形态和输入输出。保持参考的视觉吸引力，不把关键模块缩成普通标签。
>
> 科学关系：逐条给出核对后的输入、处理、输出、时序、训练更新与部署边界。标签和公式提供准确文本；不编造模块内部、损失、权重、性能图或结论。
>
> 版式与文字：中文短标签，英文模块名完整，正文在整图显示时可读。插画与独立标签留出边界，便于后续精排。公式放在所属模块近旁或补充带，不占掉插画位置；箭头接清楚的端口，不穿文字。
>
> 输出前对照指定草稿，逐区检查视觉覆盖和重点模块；方法内部、训练和部署均不能在简化过程中丢失插画。科学连线与文字仍以论文为准。

若用户要去其他生图模型试用，交付一段可独立复制的完整提示词，并说明应附上哪张草稿和哪个论文版本。不要假定外部模型的参数、分辨率或文字准确率；未运行过就注明尚未在该模型测试。Zeva 的 [完整提示词示例](../assets/zeva-reference/zeva-gpt-image-2.5-prompt.md) 展示了如何逐区写出保留要求，论文内容不能迁移到其他项目。

## 最后对照要看什么

- **整图同宽比较**：参考中的场景丰富度、阅读顺序、视觉重点和正文可读性是否保留；不能只靠一两处漂亮插画判定整图达标。
- **按视觉对应表逐区比较**：动作／效果、模型内部、记忆、训练、部署等实际存在的区域是否有对应素材；没有退化成空框、色条或通用图标。
- **放大检查边缘和密集区**：主体、轨迹、前后图与立体侧面没有被截断；无旧标签残留、重复文字、错误箭头和覆盖。公式新增后再检查邻近插画与连线。
- **核对科学内容与交付依赖**：原文事实、时间和参数更新关系独立复查；源码能找到原图，PDF 与预览为同一版本。编译检查只能辅助其中一部分。
