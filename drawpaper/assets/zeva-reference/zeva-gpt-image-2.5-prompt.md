请为论文《Zeva: In-Context Causal Learning for Generalizable Embodied Manipulation》生成一张完整、清晰、能激发阅读兴趣的中文插画式科研架构图。第一份附件是我非常喜欢的生图草稿，请逐区保留它的视觉元素、材质、立体感、配色和阅读顺序；论文附件用于核对科学内容。请直接输出成图。

标题：“Zeva：把交互经验变成下一次行动的上下文”。副标题：“参数固定 · 记忆更新 · 动作随上下文改变”。整体近方形、单页，米白底、深蓝文字；左栏浅蓝、中栏浅紫、右栏暖橙，Causal Prompt 使用醒目的紫色横带。信息紧凑，正文在整图显示时仍能读清，输出当前界面允许的最高质量和合适的高清尺寸。

**视觉保真是核心要求。** 保留银色金属机械臂、黑色夹爪、透明试管与烧杯、木质试管架、玻璃反光、液面变化、抓取特写、相机、动作轨迹、带具体交互画面的记忆卡、彩色 token、聚类点云和人类示范插画。每处动作执行都展示具体机械臂姿态；每处动作效果都展示真实感的前后场景；每张记忆卡都含交互缩略图。延续草稿中写实实验室微场景与立体科学模块结合的质感。不要把这些元素替换成简笔画、折线机械臂、空白矩形、通用图标或只有文字的模块。

**顶部故事带**：抓取试管失手，配夹爪局部放大图；中间并列展示“执行的动作”和“观测到的效果”，用机械臂及彩色轨迹、场景前后对照解释经验内容；右侧展示带着经验调整抓取的场景。保留草稿中的主体、视角和细节。这个故事是机制示意，不添加成功率或“重试固定次数必成功”的结论。

**左栏：交互编码 CTE。** 视觉场景经过视觉编码，已执行动作经过动作编码，实际观测到的效果经过效果表征，三路汇入带上一循环状态输入的 GRU。输出“阶段”和“交互信号”：前者用进度圆点，后者用彩色 token。每一路都要有与草稿一致的具体插画。公式 3 放在 GRU 附近，保持初始化关系。这里处理已经完成的交互，不能提前使用当前动作尚未发生的结果。

**中栏：双时间尺度记忆。** 上方 BIT 用连续的小型机器人交互卡片表现本次尝试的近期窗口。下方 PIM 用有厚度、按阶段区分的叠放记忆卡表现同一 episode 内跨次经验；卡片上保留场景缩略图。“相似则合并，否则新增”；合并评分结合阶段和效果相似度，检索只依据当前阶段。显示当前阶段查询、Top-K 检索与返回的经验卡片，并将 BIT 和检索结果分别送向 Causal Prompt。

**右栏：Cosmos3 backbone 的双路径策略。** AR Path 展示实验场景、相机和任务指令气泡：图像进入 ViT，文字进入 Language Tokenizer，编码结果进入 Self Attention。Diffusion Path 展示图像进入 VAE、带噪动作曲线进入 Action Encoder，结合 AR 上下文与 Causal Prompt 进入 Full Attention，再通过 LayerNorm 和 MLP 输出连续动作。输出端同时画彩色动作轨迹和写实机械臂。用立体模块、token 阵列和清晰端口表现内部计算，不能压缩成一个策略框。部署时标注参数固定，不画在线梯度更新，不编造去噪步数。

**Causal Prompt 横带是视觉重点。** 严格保留草稿中央那块醒目的紫色立体 Memory Context Encoder：有厚度、明暗侧面和清楚的输入输出，不能变成扁平文字框。左侧按顺序展示任务气泡、阶段进度、近期 BIT token、检索 PIM token；两路历史先经共享投影，再与任务和阶段拼接，送进 Memory Context Encoder。右侧输出一排丰富的紫色因果提示 token，用醒目的紫色箭头注入 Diffusion 的 Full Attention。公式 8 清晰放在这一带内。不要把拼接画成数值相加，也不要无依据地指定编码器层数或内部网络。

**底部训练与部署。** 训练侧保留烧杯前后变化、同任务聚类点云、阶段进度序列，以及交互轨迹的机器人插画；三个训练目标为效果预测、同任务监督对比、阶段进展，指出更新 CTE。论文未明确给出的损失表达、权重与优化日程不要补造。部署侧用六个带插画的连续步骤组成闭环：“阶段检索 → 构建提示 → 策略出动作 → 机器人执行并观测 → CTE 编码 → 更新 BIT/PIM”。动作输出、执行观测、检索和写记忆都须保留对应场景或卡片，不能只写六个文字框。保留“一次人类示范 → CTE → PIM 预热”的可选入口。

边界短注：“重试：环境复位，BIT 与循环状态重置，PIM 保留”；“新 episode：两库清空”。保留 PIM 的同一 episode 范围。

公式以论文为准，优先清晰呈现公式 3 和 8；公式 5、7 放在相应记忆区或紧凑的补充带。公式必须逐字核对，保持上下标与括号完整，尽量单行。可增加公式区空间，但不能因此删除或缩小上述插画。中文说明简短，英文模块名准确；Memory Context Encoder、Causal Prompt、Self Attention、Full Attention 拼写完整。箭头接真实端口，不穿文字，合并与检索的方向明确。没有装饰性大留白、额外性能图、重复标题或制作说明。

完成前逐区核对参考草稿：动作与效果对照、CTE 三路输入、BIT/PIM 卡片、双路径策略、紫色立体 Memory Context Encoder、训练插画、部署执行场景、人类示范，任何一处都不能因追求简洁而退化成抽象图标。优先达到“草稿原有的吸引力 + 清楚可靠的科学内容”。
