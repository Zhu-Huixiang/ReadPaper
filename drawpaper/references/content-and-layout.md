# 内容与排版规范

新图提炼内容时读本文件；已有图修订时只复查相关部分。

## 一份内容规格

把下列内容集中记录在一个工作文件中。它是画图与核验的依据，不必把全部表格画到图上。

| 记录 | 应记录的信息 |
|---|---|
| 来源 | 论文标题、版本、路径；相关节、图、公式、算法、附录位置 |
| 模块 | 名称、输入、内部计算、输出、参数归属；训练及部署是否存在 |
| 符号 | 原符号、含义、维度或类型、来源；同一字母不同含义的区分 |
| 连线 | 起点、终点、传递对象；数据流、监督、参数更新或时间递推 |
| 损失 | 完整表达式、预测量、目标量、样本来源、权重；更新和固定哪些参数 |
| 训练循环 | 数据如何获得；预训练、交替更新、采样、回放、课程等实际顺序 |
| 推理循环 | 可用观测与条件、缓存、状态更新、输出如何作用于环境及进入下一步 |
| 覆盖 | 每个关键机制/公式对应的图中位置；省略不影响机制的细节时记录理由 |
| 视觉对应（插画版） | 选定草稿的区域或素材、表达的信息、终稿位置、保留方式及检查结果；用户点名的视觉重点单独记录 |

对论文原文、附录/实现来源、通用教学展开分别记录证据。无法确认的层数、维度、损失类型与超参数保持抽象，不给出貌似精确的数值或公式。

## 从文字变成计算图

- 顶层先让读者看见各模型的输入、输出和关系，再在模型框内展开编码、融合、记忆更新、采样、预测头等实际计算。
- 输入不是一袋符号：画清分别经过什么处理、在哪里合并，以及上一时刻信息何时参与。区分拼接、求和、注意力融合和概率采样。
- 把公式放在它所属的模块或损失区。损失区必须能追溯到产生预测和监督目标的模块；模型计算与损失解释不能互不相连。
- 用一个紧凑流程表示训练迭代，用另一个流程表示部署。不要把训练才能取得的真值、参考或教师无依据地接进部署链。
- 循环模型要显示历史状态、当前观测、上一步动作及下一步缓存；前馈模型不必生造记忆循环。
- 多步预测要分清观测校正、先验外推、动作来自谁、是否读取未来观测。数据缓存、参考课程和隐状态缓存不能混成同一个 buffer。
- 训练损失的箭头表示更新对象，不能让人误读成部署输入。参数冻结与对输入保留梯度可以同时成立；只有来源明确时才画具体梯度路径。

## 数学表达与证据边界

保留论文的上下标、条件、时间步、求和范围、期望分布、范数、KL 方向、采样符号及权重。图中引用原公式号必须经过核对；新补的等式不能冒用论文公式号。

对于“PPO”“动作匹配”“接触一致”“KL”等名称，若公式对理解训练有必要且能定位到原文，应给出数学表达，不能只堆术语。原文仅给算法名时，可加必要的标准教学展开，但应以一次短注“通用展开”区分；不能声称该展开是作者的精确实现。

**不要靠每个符号后面挂剑号来管理出处。** 剑号没有普适的“冻结”含义，容易和停止梯度混淆。若原文已使用，应忠实保留并解释原文定义。新图若需新增记号，优先就地定义并在源码记录来源。

冻结模块在训练阶段用“参数固定”短注表达；停止梯度沿实际路径写清 `sg` 或 `detach()` 的含义。不能把冻结网络误画成完全不能通过它对输入求导。

中文说明保留为“本体”“记忆”“奖励头”等短标签；较长概念尽量使用已定义的论文符号。帽子已经表达预测含义时，不必给每个输出再加“预测”两个字。用紧凑图例解释必要符号，不把整个词汇表塞进图。

用户不希望图上出现“未披露”“未完整披露”“论文未展开”“依据某某重绘”等制作注记。把这些证据问题记录在规格中；图上保持适当抽象，避免无依据的具体结构。

## 排版与连线

### 密度和字体

- 默认一张完整图承载主结构、关键损失、训练与部署。根据计算关系分栏或分带，不把每个小节做成同样大的空盒子。
- 先给内容分配面积，再放节点。宽公式用宽栏；小模块不占大面积。消除没承担分组或布线作用的留白，同时保留可辨认的模块间距。
- “字号大”由正常阅读宽度的整图决定。只增加 PDF 物理尺寸或 PNG 分辨率不会改善整图缩放后的字号。
- DreamMimic 矢量样例约为近方形画布，正文 15 pt、辅助文字 13.5 pt；这是起点，不是模板尺寸限制。新图按屏幕实际可读性调整，不能把字号一直往下压。
- 结构区用清楚的分组色、深色文字与一致的描边；插画可保留参考中的材质、渐变、明暗和立体感，用于表达实体场景或突出关键模块。避免无信息的装饰、大标题占位和宽白边，不能为统一扁平风格抹掉已认可的插画质感。
- 插画版按 [插画保留与混合排版](illustrated-layout.md) 给场景和关键模块预留面积。补充公式优先放邻近公式区或补充带，不能以删除插画或把场景缩成图标来换空间。

### 单行公式

当公式放不下，依次尝试：删冗余文字 → 重新分配栏宽/整行带 → 用定义过的紧凑记号 → 移出公式编号或旁注 → 调整局部布局。不要改公式含义、漏项或用整体缩放挤进去。

一条等式尽量一行；几个不同的等式可以逐行对齐。特别检查策略条件分布、输出特征向量、总损失、重建损失、多步匹配损失与 PPO 等容易被断行的表达式。确实超长时才在数学上合理的地方分行，以可读性优先。

上下标、期望下标、分式、范数和大括号会显著增加实际高度。根据**排版后的边界**安排间距，不能只看文字基线或给定的框高。

### TikZ 中容易反复出错的地方

- `minimum height` 只是下限。内容可能撑高节点；用实际节点锚点及 `fit`/相对定位确定面板与连接，不要假设它就是固定高的矩形。
- 给公式编号独立空间，和公式右边留出距离。用不可断行公式盒保住单行时，仍必须检查宽度溢出；它本身不解决拥挤。
- 分隔横线与标题、公式的实际边界分离，尤其留意求和下标、帽子、剑号和较深的下降部。
- 对齐的节点使用直线到实际 `north/south/east/west` 锚点；需要绕行才使用折线。不要从框中心穿过字，也不要用很短的最后一段造成箭头方向错觉。
- 旁注放在独立可用区域，不挂在公式编号或短箭头上。公式盒旁的一行“采样”等小字也要计入排版面积。
- 汇合点用明确分支/连接点；无关线路交叉留间隙或作桥接。背景遮罩只可消除无关交叉歧义，不能拿白块掩盖走线穿字的问题。
- 不同线型含义在全图统一：例如实线信息流、金色虚线监督、红色虚线更新。若实线同时用于分组边界，应通过箭头和图例保持区分；具体配色可随论文调整。
- 修改总损失、教师目标或某个单行公式后，复查整个面板及相邻横线、旁注、箭头，不只看修改的那一行。

## 交付前检查

分两轮做，不以编译成功替代核验。

**内容轮**

- 每个模型都有能解释其计算的输入、内部结构、输出。
- 关键公式与论文一致；损失的目标、数据来源与更新对象明确。
- 训练迭代与部署过程自洽；时间和因果方向正确。
- 请求覆盖的机制均可在图中定位；补充教学内容与论文事实可区分。
- 图例解释符号，未引入没有定义的标记或猜测维度。

**视觉轮**

- 最终 PDF 单页；新排文字可选择、字体可用，关键公式与计算连线来自矢量排版。混合图可保留生成插画和经过核对的位图标签；检查其实际阅读尺寸与清晰度，如实区分文字可编辑与插画需替换的部分。
- 编译日志没有未解决的缺字、缺字体、越界错误；核查 overfull/underfull 警告的实际影响，不把无害警告等同于图坏了。
- 以约 1100 像素宽查看**整张图**，无需靠局部截图才能读核心结构和正文；必要时使用实际聊天显示宽度再次检查。
- 高清检查所有密集公式、公式编号、上/下标、图例、标题和分隔线；没有文字互相压住或碰边。
- 箭头方向一眼可辨，线不穿字，交叉不被误认作汇合。
- 内容紧凑但不挤压；重要公式没有因排版被无意分行或缩得过小。
- 插画版对照选定草稿检查全图和重点区域：方法内部、训练与部署的视觉元素均有对应；主体、动作效果、材质与关键模块的视觉重点得到保留。裁切没有断主体、留下错误箭头、重复标签或漏掉前后对照。
- 插画分辨率按源图及实际放置大小评估；导出更大的 PNG 不等于素材增加细节，不将混合图称作纯矢量或无限放大清晰。
- 最后一次修改后已重新编译、渲染并亲自查看；PDF、预览、源码是同一版本。
- 源码包包含全部图片依赖，相对路径可解析；原始草稿、终稿和提示词未混淆，已满意的版本保留原样。

脚本检查只能给出页数、文本、边界和日志证据。不能自动证明节点内部无重叠、插画质感与草稿一致，也不能证明一条科学连线正确。检查报告保留“需要视觉检查”的状态，不把机器检查通过说成已验收。
