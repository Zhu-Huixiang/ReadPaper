## 插画混合终稿：Zeva

用户在 2026-09-11 明确表示对 `zeva-illustrated-v2.pdf` 很满意，并要求将此次插画经验写入技能。这组资产保留了同一次迭代的草稿、终稿与素材依赖：

- [选定的生图草稿](../assets/zeva-reference/zeva-illustrated-v1-imagegen-draft.png)：原始 1254 × 1254 图片，字节不变。
- [完整终稿预览](../assets/zeva-reference/zeva-illustrated-v2.png) 与 [单页 PDF](../assets/zeva-reference/zeva-illustrated-v2.pdf)：均为用户满意版本的字节副本；将草稿与终稿按相近宽度查看。
- [TikZ 源文件](../assets/zeva-reference/zeva-illustrated-v2.tex)：与上述草稿放在同一目录即可解析唯一的图片依赖。草稿文件名中的 `v1` 指素材版本，终稿仍是 `v2`，不要因此替换成另一张图。
- [完整生图提示词](../assets/zeva-reference/zeva-gpt-image-2.5-prompt.md)：展示逐区描述插画和科学关系的写法；供用户在 GPT Image2.5 自行试用，未在该模型测试。跨论文使用时需要重写全部科学内容。

v2 的关键做法是通过 37 个 `graphicx` 裁切视窗复用原插画，主文字、关键公式和计算连线用 TikZ 重排。机械臂动作与效果、场景记忆卡、双路径策略、紫色立体 Memory Context Encoder、训练和部署插画均有对应。精确补充公式置于邻近区域及底部公式带，保留插画面积。37 是该例的实现数量，不是新图的要求。

这是**插画与矢量排版混合的 PDF**；部分原模块标签仍在位图中，不能宣称全部元素可单独编辑或无限放大清晰。3300 像素宽的终稿 PNG 不会增加原插画的细节。源码里的 macOS 字体设置和裁切坐标依赖本例环境与图片；新图需检测可用字体、按实际素材计算裁切区域，不能直接套用。源码注释中的工作规格路径用于追溯原项目，并非编译依赖。


## 矢量终稿：DreamMimic

该样例来自用户在 2026-09-08 明确满意的 DreamMimic 方法架构图。它是**版式参考和可编辑示例，不是原论文，也不是新图的科学来源**。其中包含教学补充符号；不应沿用为其他论文的事实。

- [完整预览](../assets/dreammimic-reference/accepted.png)：先查看整图，观察正文大小、面板密度、损失区和底部流程。
- [单页矢量 PDF](../assets/dreammimic-reference/accepted.pdf)：用户指定版本的字节副本。
- [TikZ 源文件](../assets/dreammimic-reference/accepted.tex)：用于借鉴样式和节点写法；改编时清除全部论文专有内容，再按当前规格绘制。

样例结构：上部各模型输入输出与内部处理，中部关键损失及控制逻辑，下部训练与部署循环；接近方形的单张画布。它展示的是一种内容驱动的排布，不要求未来论文具有三个模型或完全相同的分区。

样例约为 37 × 35.8 cm，正文 15 pt，辅助文字 13.5 pt，面板标题 17 pt。参考预览宽 1100 px。先保证整图可读，不能盲目复制尺寸后塞入更多内容。

源文件使用 XeLaTeX、standalone、TikZ、fontspec、xeCJK 与 Latin Modern 数学字体；Arial 和 STHeiti 的设置是该次 macOS 环境选择。其他环境应检测并替换为可用字体，而不是安装整套无关软件或保留失效的绝对字体路径。

此前迭代得到的改进已经归入 [内容与排版规范](content-and-layout.md)：减少白边、增大可读字号、长公式保持单行、直连箭头、为采样标签及公式编号留空间、修正教师目标/横线/PCG 遮挡、删除制作注记。不要复刻旧版的错误。

一个后续教训：样例用剑号标注补充记号和通用展开，用户曾误以为它代表冻结梯度。因此**沿用布局，但不要把这套剑号标记习惯推广到新图**。冻结参数与停止梯度必须按当前论文独立解释。
